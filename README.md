**一包安装，一键启动。让你的 QQ 小号，变成有性格的 AI 聊天伙伴。**

不想研究部署教程，不想挨个下载运行环境，更不想对着配置文件反复折腾？大肥鱼把 Python、Node.js、AstrBot、NapCat 和配套插件整合进一个 Windows 安装包。**下载一个 EXE，跟着向导完成首次设置，以后双击「启动大肥鱼」即可启动助手。**

## 把折腾留给程序，把聊天留给你

- **一个安装包，整合整套运行环境。** 常用组件与配套插件已打包，不用在多个项目之间来回找下载、装依赖、对配置。
- **首次跟着向导走，日常双击就启动。** 安装、连接、角色设置和扫码登录按步骤引导；设置完成后，用桌面快捷方式启动助手与控制台。
- **聊天就在 QQ，不必换个地方培养习惯。** 用你的大号联系机器人小号，把 AI 聊天带进熟悉的对话窗口。
- **名字你来起，性格你来定。** 支持自定义角色名字、性格描述和表情包使用偏好；开启语音后，还能设置声音描述。
- **想要语音、想要长期记忆，按需开启。** 基础聊天可以先用起来，语音和记忆默认关闭。语音功能有明确的费用确认入口，能力与开销由你选择。
- **一个控制台，管好整个助手。** 启停服务、修改连接、编辑角色、切换 QQ 小号集中管理，不用来回找后台。
- **中途关了，也能接着装。** 支持安装中断后继续，失败步骤可重试；同一安装目录复用后台，减少重复启动带来的混乱。
- **程序和个人数据分开放。** 程序放在 `program/`，设置、聊天数据与日志放在 `userdata/`，便于管理；升级补充默认数据时不覆盖已有个人文件。
- **海洋蓝界面，清楚才好用。** 用直观的步骤、明确的按钮和简洁的页面，把部署流程变成看得懂的操作。

## 从下载到聊天，跟着向导就行

1. **下载并双击 EXE。** 选择不含中文或空格的安装目录，预留至少 10 GB 空间。
2. **填连接，选角色。** 填写 QQ 大号和 DeepSeek API 密钥，设置名字与性格；语音、记忆按需开启。
3. **等待准备完成，扫码登录小号。** 首次安装需要联网，表情资源会从上游获取。
4. **开始聊天。** 用大号联系小号；以后双击桌面的「启动大肥鱼」，即可启动助手。

首次使用仍需准备 QQ 账号和 API 密钥，并完成扫码登录；「一键启动」指首次设置完成后的日常启动，不代表免账号、免联网或免 API 费用。

请使用 QQ 小号。第三方登录存在账号受限或封号风险。Windows 10 / 11 64 位为目标运行环境；安装目录不要包含中文或空格。

当前为 **v0.1.0-preview.1 预览版**。已通过 190 项 Python 测试，以及实际 EXE 的启动、解包、后台复用和中断续装检查；真实 QQ 登录及付费接口尚未实测，安装包未做代码签名。具体范围见 [构建与验证记录](docs/发布准备-2026-11-09.md)。

## 服务与费用

- 聊天：DeepSeek API，按平台规则计费。
- 语音：豆包音频生成模型 1.0。校验、试听、生成声音可能消耗额度或产生费用。
- 记忆：硅基流动的 `BAAI/bge-m3` 向量接口，价格以平台当时说明为准。参与向量化的文字会发送至该服务。

新安装默认关闭语音和长期记忆，只配置聊天即可继续。启用语音需要确认费用提示；关闭后会停用相关服务及唱歌插件。默认音色为甜妹音。保存未变更的语音凭据和导入设置不会自动生成试听；主动校验新凭据或试听仍可能产生费用。原有已配置安装迁移后保留原来的能力开关。

## 日常管理

桌面快捷方式「启动大肥鱼」打开本地控制台，可启动或停止服务、编辑角色、修改连接、切换 QQ 小号。同一安装目录的窗口共用一个后台；关闭窗口后，已启动的服务继续运行。“停止并退出”才会停止服务。切换小号保留 QQ 客户端的聊天与登录数据；卸载清理本助手安装目录，不清理外部 QQ 数据，并要求明确确认。

后台登录信息默认折叠，密码默认隐藏。点击导出才会生成 `userdata/我的信息.txt`。状态文件中的密钥使用 Windows DPAPI 保护；第三方运行配置仍需要明文密钥，不能把整个数据目录视为已加密。电脑睡眠或关机时，助手会离线。

新安装将程序放在 `program/`，个人设置、聊天数据与日志放在 `userdata/`。旧安装迁移会先复制并保留旧文件；迁移失败不激活不完整的新目录。程序替换前先复制校验，失败恢复旧程序；升级补充默认数据，不覆盖已有个人文件。

已保存的角色与服务配置不会因更新默认预设而自动覆盖。旧用户如需使用新预设，应在角色设置中主动修改。

## 本地开发

界面为原生 HTML / CSS / JavaScript，服务端使用 Python。Python 3.10+ 可运行测试和模拟界面：

```powershell
python -m unittest discover -s tests -t .
node --test tests/frontend/*.cjs
python dev/fake_wizard.py
python dev/fake_wizard.py --status
```

浏览器回归需要 Node.js 22+ 和 Microsoft Edge。模拟程序默认使用本地 8765 端口，地址及访问令牌会打印到终端。界面数据来自假后端，不能用于真实登录或证明已完成安装；不要在预览中填真实密钥。预览中的安装路径仅供展示，所有写入均隔离在新建的临时目录内。

## 构建安装包

在 Windows、Python 3.12+ 环境中，准备以下文件到 `downloads/`：

- `astrbot-src.zip`：AstrBot 4.29.3 源码。
- `astrbot.zip`：对应版本后台静态资源。
- `napcat-node.zip`：NapCat.Shell.Windows.Node v4.18.41。

```powershell
python build/build.py --check-inputs
python build/build.py
```

`--check-inputs` 只检查本地输入，列出缺失或损坏的文件，不联网、不启动服务。格式检查和本地 SHA-256 用于发现损坏、记录输入，不代表官方签名验证。

正常构建会联网下载运行时、安装依赖、预热第三方组件，输出 `dist/大肥鱼 QQ 助手.exe`、同名 `.sha256` 校验文件和 `input-manifest.json`。它会启动临时服务，不等同于单纯的界面预览。`--skip-download` 只跳过运行时文件下载，后续依赖安装和插件预热仍可能联网。输入检查不通过时保留已有构建目录。

构建中断后，可用 `python build/build.py --skip-download --resume` 复用输入文件未变化的已完成阶段。发布包不内置两套预设表情图片；首次安装会从上游获取，需要网络。原素材的许可见各自来源，本项目不为这些素材提供额外授权。
