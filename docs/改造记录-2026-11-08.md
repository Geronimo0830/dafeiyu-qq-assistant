# 可选服务与安装可靠性改造

日期：2026-11-08。按已确认方向实施：语音与记忆可选、同一安装目录统一后台、程序与个人数据分离。保持现有极简海洋蓝界面。

## 使用变化

- 新用户只需要 QQ 大号和聊天服务密钥即可继续。语音与长期记忆默认关闭，可分别启用；原来已配置的用户迁移后保留原能力。
- 开启语音仍需确认费用提示。修改无关设置、沿用已有语音凭据、导入角色时不再自动生成语音样本。主动验证新凭据、试听和实际语音使用仍可能收费。
- 关闭语音同时停用相关语音配置和唱歌插件，关闭记忆停用记忆插件与本项目的向量提供商。应用配置完成后再连接 QQ。
- 同一安装目录的窗口连接同一后台。关闭界面不停止正在运行的服务；“停止并退出”才会停止服务。
- 后台登录信息仅显示在页面，用户主动导出后才生成明文文件。

## 文件与数据

新安装布局：

```text
安装目录/
  layout.json
  program/                 程序与默认资源
    app/
    runtime/python/
    astrbot/
    napcat/
    pack/
  userdata/                个人数据与工作配置
    state.json
    astrbot/data/
    napcat/
    pack/
    logs/
```

旧版迁移先复制，再激活新目录，保留原文件；旧服务仍运行时拒绝迁移。更新程序先复制并校验，再替换，失败时恢复旧程序。解包只补充缺少的个人数据文件，不覆盖现有聊天库、角色设置或密钥。中断后的状态根据实际完成步骤恢复。

AstrBot 的程序路径与数据路径通过官方 v4.29.3 的 `ASTRBOT_ROOT` 和 `--webui-dir` 分离，未使用目录链接。对应源码：[路径实现](https://github.com/AstrBotDevs/AstrBot/blob/v4.29.3/astrbot/core/utils/astrbot_path.py)、[启动参数](https://github.com/AstrBotDevs/AstrBot/blob/v4.29.3/main.py)。

## 同步修复

- 切换 QQ 只清理本项目的账号选择与缓存，保留外部 QQ 客户端的聊天和登录数据。
- 停止服务先核对进程可执行路径和创建时间，拒绝操作被其他程序复用的 PID。
- 状态保存采用跨进程文件锁、原子替换和三方合并；同字段冲突明确报错。
- ZIP 和安装包在解压前检查路径；卸载验证安装归属、路径与目录链接，保留共享缓存及外部 QQ 数据。
- 本地 HTTP 服务检查 Host 和 Origin。服务开关及收费确认在后端再次验证。
- 修复接口失败仍显示成功、进度请求错误导致页面异常、过期校验覆盖新输入、页面返回时重复启动等问题。
- 构建脚本适配新布局，预热通过适配层跳过自动语音试听，打包前清理预热凭据及状态。第三方源码和许可证保留。
