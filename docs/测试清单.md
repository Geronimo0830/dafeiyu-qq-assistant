# 验收清单

## 模拟界面

- 六个安装步骤均使用海洋蓝界面，页面显示作者 Xean。
- 连接页和角色页的语音区初始锁定，取消保留锁定，确认后允许输入；锁定时不发送试听或语音校验请求。
- 已保存密钥留空不覆盖；无效输入阻止保存并显示原因。
- 新安装只填聊天服务即可继续；语音和记忆分别开启/关闭，禁用项不要求凭据。
- 角色姓名、性格不能为空；启用语音时音色不能为空；至少选择一套表情包。
- 沿用已保存语音凭据、保存角色和导入配置不自动调用 TTS；主动校验和试听需费用确认。
- 安装进度反映完成步骤数，失败时显示重试入口。
- 二维码加载、失效、刷新、已扫码和成功状态正确。
- 完成页账号折叠、密码默认隐藏，显示/隐藏与关闭回退提示有效。
- 控制台在线、离线、启动中、扫码、错误状态可见，设置和重新连接页风格一致。
- 卸载需输入确认词，取消不调用卸载；退出和切换账号的取消不调用相关接口。
- 窄屏、键盘焦点、折叠帮助、费用蒙版及弹窗不溢出。
- 接口失败保留当前页面，不显示退出/停止成功；进度断连后可恢复，旧校验响应不覆盖新输入。

## 本地自动化

- Python：`python -m unittest discover -s tests -t .`。
- 前端：`node --test tests/frontend/*.cjs`。
- 覆盖：并发状态保存、单后台锁、PID 复用、恶意压缩路径、更新失败回退、旧布局迁移、保留个人数据、可选服务与本地接口权限。

## 真实安装（发布前执行）

- 在干净 Windows 10 / 11 机器构建并安装。
- 验证许可文件与来源说明进入最终目录。
- 使用测试账号和受控额度校验真实接口，核对费用提示。
- 验证二维码登录、文字回复、语音与记忆功能。
- 验证重启控制台、停止/启动、改设置、断点续装与卸载。
- 分别验证两个可选服务全部关闭、只开语音、只开记忆、全部开启；关闭后确认对应插件不再调用接口。
- 验证旧安装迁移及失败恢复，比较聊天库、角色配置和密钥；保留旧目录直到人工核验完成。
- 验证 QQ 客户端聊天目录在切换账号与卸载后不受影响。
- 重复打开安装/控制台窗口应连接同一个后台，关闭所有窗口后服务继续运行。
- 不把模拟截图、假二维码或单元测试通过当作真实服务已验证。
