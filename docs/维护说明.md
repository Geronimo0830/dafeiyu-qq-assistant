# Xean 维护说明

## 视觉约定

产品名：大肥鱼 QQ 助手；项目作者署名：Xean。采用浅海蓝背景、深蓝文字和青蓝操作按钮。安装页和控制台共用头部与表单样式。避免恢复旧版蓝紫侧栏、角色口头禅及重复提示。

## 修改边界

- 安装根目录保留，程序放在 `program/`，个人数据放在 `userdata/`，`layout.json` 标记布局版本。读取路径统一使用 `paths.Layout` / `state_path`，不再拼接旧目录。
- 旧安装采用复制迁移，保留原目录；先停止旧服务，再迁移。迁移会重做配置、插件导入和快捷方式，不覆盖已保存的角色与聊天。
- 语音、记忆默认关闭，旧版已配置安装保留原能力。开关贯穿前端、凭据校验、导入和插件启停。费用确认不能只依赖前端。
- 同一安装根目录只有一个后台持有系统文件锁；窗口关闭不等于停服务。状态文件使用跨进程锁和三方合并，同字段冲突显式报错。
- 安装/应用设置先完成插件配置，再连接 QQ。`import_runner.py` 适配第三方导入工具，禁止导入阶段自动生成语音样本；不修改 vendor 许可和来源。
- 更新先复制校验后替换，失败回退。操作进程前校验可执行路径与创建时间；禁止删除外部 `Tencent Files`。
- 已保存的用户配置优先于默认预设，更新默认文案不强制改写旧用户配置。
- 角色、音色的默认来源为配置包；校验与插件兜底音色需同步维护。
- 自有部分采用完整未改写的 PolyForm Noncommercial 1.0.0；保留 NOTICE 中的版权与必需声明。第三方许可及署名分别保留，不把项目的非商业限制套用于第三方代码。

## 发布前

运行自动化测试；用模拟后端检查六步安装与控制台；在干净 Windows 环境实际构建、安装、扫码、退出重开及卸载。模拟测试和截图不能代替真实发布验收。为每个新安装包生成新的校验值，不复用旧版本数值。

状态文件中的 DPAPI 凭据绑定当前 Windows 用户；手动复制 `userdata/` 到另一台电脑不能保证可直接解密。运行配置可能包含明文密钥。后台凭证仅在主动导出时写文件，诊断材料不得直接打包整个数据目录。
